How to run it

  1. Zoom 100 %, screen brightness normal, no glare on the screen.
  2. Choose I = 20. Both fields look the same.
  3. Press +1 slowly. When you can just see the edge, press “I can see the edge”.
  4. Repeat 2–3 times for the same I (press “Start again”), then do I = 100 and I = 200.
  5. Tip: use “Hide numbers” so the value does not bias you.
